# Emotion Detection CNN

Simple educational convolutional neural network implementation for facial
emotion detection. The repository contains a minimal NumPy-based CNN in
`cnn.py` and a small dataset layout under `data/`.

Usage
-
- Install dependencies: `pip install -r requirements.txt`
- Train or import `EmotionCNN` from `cnn.py` and run `train(...)` with your
  preprocessed datasets.

Notes
-
- This is a minimal, educational implementation using only NumPy (no deep
  learning frameworks). It's intended for learning and experimentation.
